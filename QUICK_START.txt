═══════════════════════════════════════════════════════════════════════════════
TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

"Permission denied" / "WinError 10013"
  → Run as Administrator
  → Scapy needs raw socket permissions

"No module named scapy"
  → pip install scapy

"Address already in use"
  → Another program is using the port
  → Change port: AEGIS_BACKEND_PORT=9000 python run_all.py

Simulator just hangs
  → Wait. It's generating packets (real-time, ~10-100 packets/sec)
  → 4-hour sim takes 4 hours. Check progress with window count.
